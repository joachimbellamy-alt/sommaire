Comment faire : remplissez la fiche puis cliquez sur Télécharger en PDF ou Télécharger en Word. Rien n'est obligatoire et rien n'est envoyé sur Internet : la fiche reste sur votre ordinateur. Pour imprimer une fiche à remplir à la main, cliquez sur Fiche vierge.
Vos élèves : choisissez votre nom dans « Je suis » ; vos élèves EBEP s'affichent et l'en-tête se remplit tout seul. La liste n'est pas conservée : elle s'efface quand vous fermez la page.

Mes élèves EBEP choisissez votre nom : vos élèves s'affichent

Avec le fichier de suivi EBEP (Google Sheets) : dans Google Sheets, faites Fichier › Télécharger › Microsoft Excel (.xlsx), puis déposez le fichier ici. Choisissez ensuite votre nom : seuls vos élèves EBEP actifs s'affichent.

Vous pouvez aussi glisser le fichier dans ce cadre. Colonnes reconnues : Nom, Prénom, Classe, Professeur principal, Ancienneté (1, 2 ou 3). Seul le nom est indispensable.
