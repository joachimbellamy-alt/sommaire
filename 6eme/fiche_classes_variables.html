Les classes grammaticales variables

Le groupe nominal
Déterminant

Il se place devant le nom.

Varie en genre (masculin ou féminin) et en nombre (singulier ou pluriel) :

  • articles : le, la, l', les, un, une, des, du, au, aux
  • possessifs : mon, ton, son, sa, ses, notre, leur…
  • démonstratifs : ce, cet, cette, ces

le cyclope, ses moutons

je le remplace par un, une ou des : ce monstre → un monstre.

Nom commun

Il désigne un être, une chose, un lieu ou une idée. C'est le noyau du groupe nominal.

👀 Tout ce que tu vois autour de toi est un nom : la table, la fenêtre, le cahier…

Varie en nombre : un monstre → des monstres

Son genre est fixe : le cyclope, la caverne.

je le remplace par un autre nom : le monstre → le géant.

Nom propre

Il commence par une majuscule : une personne, un lieu précis.

Ulysse, Polyphème, Méduse

je le remplace par un autre nom propre : Ulysse navigue → Thésée navigue.

Adjectif

Il précise le nom : il dit comment est l'être ou la chose.

S'accorde en genre et en nombre avec le nom

masculinféminin
singuliercruelcruelle
plurielcruelscruelles

le monstre cruel, la sombre caverne

je le remplace par un autre adjectif : le monstre cruel → le monstre affreux.

Pronom

Il remplace un groupe nominal pour éviter une répétition.

Varie en genre, en nombre et en personne

Sujets : je, tu, il, elle, on, nous, vous, ils, elles

Compléments : me, te, se, le, la, l', les, lui, leur, nous, vous, en, y

⚠️ le, la, les : devant un nom → déterminant (le cyclope) ; devant un verbe → pronom (Ulysse le trompe).

Le cyclope affreux dévore les marins.
→ Il les dévore.

je remplace tout le groupe nominal par un pronom : Le cyclope affreux dévore → Il dévore.

Verbe

Il exprime une action ou un état. C'est le noyau de la phrase.

Se conjugue : il change selon la personne, le nombre, le temps et le mode

  • je dévore, nous dévorons, il dévora, il a dévoré
  • Il s'accorde avec son sujet : le monstre rugit / les monstres rugissent.
  • Dans un temps composé, les deux mots forment le verbe : il a dévoré.

Ulysse ruse. Méduse pétrifie. Le cyclope est furieux.

je le remplace par un autre verbe : Le cyclope dévore → Le cyclope avale,
ou je change le temps : Le cyclope dévore → Le cyclope dévorera.

🔒 Et les mots invariables ?

Ils ne changent jamais de forme : à, de, dans, avec, et, mais, ou, puis, enfin, très, bien, ne… pas.

🔄 Le principe de substitution (la commutation)

Je remplace un mot par un autre mot, à la même place.
Si la phrase reste correcte, les deux mots sont de la même classe grammaticale.
