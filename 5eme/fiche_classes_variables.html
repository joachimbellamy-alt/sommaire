Les classes grammaticales variables

Le groupe nominal
Déterminant

Il se place devant le nom et l'annonce.

Varie en genre et en nombre : le / la / les

  • articles : le, la, l', les, un, une, des, du, au, aux
  • possessifs : mon, ton, son, sa, ses, notre, leur…
  • démonstratifs : ce, cet, cette, ces

le chevalier, ses aventures

je peux le remplacer par ce ou un.

Nom commun

Il désigne un être, une chose, un lieu ou une idée. C'est le noyau du groupe nominal.

Varie en nombre : un chevalier → des chevaliers

Son genre est fixe : le lion, la forêt.

le chevalier, la forêt, le courage

je peux mettre le ou un devant.

Nom propre

Il commence par une majuscule et désigne une personne, un lieu ou un animal précis. Souvent sans déterminant.

Yvain, Laudine, Brocéliande

il peut remplacer tout un groupe : le chevalier → Yvain.

Adjectif

Il précise le nom : il dit comment est l'être ou la chose.

S'accorde en genre et en nombre avec le nom

courageux → courageuse → courageuses

le chevalier courageux, la sombre forêt

je peux le remplacer par un autre adjectif (fier, fidèle) ou l'enlever.

Pronom

Il remplace tout un groupe nominal (ou un nom propre) pour éviter une répétition.

Varie en genre, en nombre et en personne

je, tu, il, elle, nous, vous, ils, elles · le, la, les, lui, leur · me, te, se

Le chevalier courageux combat le géant.
→ Il le combat.

il remplace tout le groupe, pas un seul mot. Attention : le, la, les pronoms se placent devant le verbe.

Verbe

Il exprime une action ou un état. C'est le noyau de la phrase.

Se conjugue : il change selon la personne, le nombre, le temps et le mode

je combats, nous combattons, il combattit, il a combattu

Il s'accorde avec son sujet : le lion suit / les lions suivent.

Yvain combat. Laudine pardonne. Le lion est fidèle.

je peux le mettre à un autre temps (hier, demain) ou l'encadrer par ne… pas.

Dans un temps composé, les deux mots forment le verbe : il a combattu.

🔒 Et les mots invariables ?

Ils ne changent jamais de forme : à, de, dans, avec, et, mais, ou, puis, enfin, très, bien, ne… pas.

Ils n'ont pas de place dans ce tableau : dans l'exercice, on les ignore.

🔄 Astuce : la commutation

Pour trouver la classe d'un mot, je le remplace par un autre à la même place. Si la phrase reste correcte, les deux mots sont souvent de la même classe.

Le chevalier → Ce chevalier : le est un déterminant.
