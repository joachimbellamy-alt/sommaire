Les classes grammaticales variables (1/2)

Le groupe nominal
Déterminant

Il se place devant le nom.

Il varie en genre et en nombre.

le, la, les, un, une, des, ce, cette, son, ses…

Exemple : le chevalier, ses aventures

🔄 Test de substitutionJe le remplace par un, une ou des :
ce chevalier → un chevalier

Nom commun

Il désigne un être, une chose ou une idée.

Il varie en nombre.

un chevalier → des chevaliers

🔄 Test de substitutionJe le remplace par un autre nom :
le chevalier → le lion

Nom propre

Il commence par une majuscule.

🔄 Test de substitutionJe le remplace par un autre nom propre :
Yvain combat → Gauvain combat

Adjectif

Il précise le nom : il dit comment il est.

Il s'accorde avec le nom.

courageux → courageuse

Exemple : le chevalier courageux

🔄 Test de substitutionJe le remplace par un autre adjectif :
le chevalier courageux → le chevalier fidèle

Les classes grammaticales variables (2/2)

Pronom

Il remplace tout le groupe nominal.

Il varie en genre, en nombre et en personne.

il, elle, ils, elles, le, la, les, lui…

🔄 Test de substitutionJe remplace tout le groupe nominal par un pronom :
Le chevalier courageux combat → Il combat

Verbe

Il dit une action ou un état.

Il se conjugue.

  • je combats, nous combattons
  • Il s'accorde avec le sujet.

🔄 Test de substitutionJe le remplace par un autre verbe :
Yvain combat → Yvain attaque
ou je change le temps :
Yvain combat → Yvain combattra

🔄 Le principe de substitution

Je remplace un mot par un autre mot, à la même place.
Si la phrase reste correcte, les deux mots sont de la même classe.

chevalierlion

🔒 Les mots invariables

Ils ne changent jamais :
à, de, dans, et, mais, très, ne… pas

Dans l'exercice, on les ignore.
