Se tester : les classes grammaticales variables

Le groupe nominal
Déterminant

Il se place devant le nom.

↔ Il varie en genre et en nombre.

Exemples : le, la, les, un, une, des, ce, cette, son, ses…

🔄 Test de substitution
Je le remplace par un, une ou des :
ce chevalier → un chevalier
Nom commun

Il désigne un être, une chose ou une idée.

↔ Il varie en nombre.

🔄 Test de substitution
Je le remplace par un autre nom :
le chevalier → le lion
Nom propre

Il commence par une majuscule.

🔄 Test de substitution
Je le remplace par un autre nom propre :
Yvain combat → Gauvain combat
Adjectif

Il précise le nom : il dit comment il est.

↔ Il s'accorde avec le nom.

courageux → courageuse

🔄 Test de substitution
Je le remplace par un autre adjectif :
le chevalier courageux → le chevalier fidèle
Pronom

Il remplace tout le groupe nominal.

↔ Il varie en genre, en nombre et en personne.

Exemples : il, elle, ils, elles, le, la, les, lui…

🔄 Test de substitution
Je remplace tout le groupe nominal par un pronom :
Le chevalier courageux combat → Il combat
Verbe

Il dit une action ou un état.

↔ Il se conjugue.

Il s'accorde avec le sujet.

🔄 Test de substitution
Je le remplace par un autre verbe :
Yvain combat → Yvain attaque
ou je change le temps :
Yvain combat → Yvain combattra

🔄 Le principe de substitution

Je remplace un mot par un autre mot, à la même place.
Si la phrase reste correcte, les deux mots sont de la même classe.

🔒 Les mots invariables

Ils ne changent jamais de forme.

Dans l'exercice, on les ignore.
